# 链享浏览器 v1.4.6 发布说明

发布日期：2026-08-14
平台：Windows amd64

## 本次更新

- 同步工作台继续采用左侧实例选择、右侧操作台布局，可按分组筛选、批量选择并设置主控窗口。
- 保留当前活动网页的点击、Enter/Tab/Esc、输入内容、滚动位置和页面跳转同步。
- 支持窗口批量平铺、层叠、最大化、最小化和恢复操作。
- 支持向焦点输入框批量写入、清空文本；未聚焦输入框时会显示对应实例的失败原因。
- 支持标签页批量创建、跳转、刷新和关闭，并可从主控窗口覆盖同步全部普通网页标签页。
- 批量操作支持部分成功结果；覆盖同步先复用一个页面再关闭旧页，避免浏览器因失去最后一个标签页而退出。
- 所有同步与批量操作均通过本机 CDP 调试通道完成，应用退出时会自动释放同步连接。
- Windows 下官方 Chrome 151 在启动后两分钟内触发 `0x80000003` 断点异常时，应用会保留原启动参数和临时代理自动恢复一次；连续失败仍会记录并上报异常。
- 本地程序、Windows 安装包和便携包统一升级为 `1.4.6`。

## Windows 产物

```text
build/bin/lianxiang-browser.exe
publish/output/LianXiang-Browser-Setup-1.4.6.exe
publish/output/LianXiang-Browser-1.4.6-windows-amd64-portable.zip
publish/output/SHA256SUMS-1.4.6.txt
```

SHA-256：

请以 `publish/output/SHA256SUMS-1.4.6.txt` 为准。该文件同时包含本地 EXE、安装包和便携 ZIP 的 SHA-256，清单路径相对于仓库根目录。

发布脚本会在每次构建前删除旧版本 Windows 输出，完成后删除 `publish/staging/` 临时目录。

- 安装版包含应用本体、默认配置、Xray 和 sing-box；若发布目录存在有效 Windows Chromium 内核，也会一并打包。
- 便携版解压后可直接运行目录中的 `lianxiang-browser.exe`。
- 两种版本首次启动都会初始化空的数据目录，不会打包开发环境的 `data/app.db`、账号、Cookie、Token、代理订阅或 `.env`。

## 升级说明

- 升级前请停止窗口同步并退出链享浏览器；已打开的浏览器实例可按需保留或关闭。
- 已安装旧版本可直接运行 v1.4.6 安装包覆盖更新；安装脚本会保留安装目录中的用户数据。
- 便携版建议先备份旧目录，再用新版本程序文件覆盖；不要删除原有 `data` 目录。
- v1.4.6 不新增数据库迁移，现有实例、书签、代理、插件和用户数据可直接使用。

## 验证范围

- Go 后端全量测试与静态检查。
- Chrome 151 Windows 子进程断点退出码识别及单次恢复逻辑测试。
- 窗口同步、窗口管理、文本和标签页批量操作后端编译与调用绑定检查。
- TypeScript 检查与 Vite 生产构建。
- Windows 本地 EXE 构建、版本资源与嵌入图标检查。
- NSIS 安装包与便携 ZIP 构建。
- 产物文件名、文件清单、敏感文件排除和 SHA-256 校验。

## 已知限制

- 当前同步范围是浏览器活动网页，不包括 Chrome 地址栏、书签栏、扩展弹窗、下载框和系统对话框。
- 页面结构差异较大或窗口尺寸差异明显时，基于页面坐标的点击同步可能出现偏差。
- Windows 可执行文件和安装包尚未进行代码签名，系统可能显示未知发布者或 SmartScreen 提示。
- Linux、macOS 发布脚本仍保留，但 v1.4.6 本次只验证 Windows amd64 产物。
- Xray、sing-box 和用户自行配置的 Chromium 内核属于第三方二进制，应独立核对来源和许可。
